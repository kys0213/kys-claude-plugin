# herdr-app 확장

> herdr-app 창에서 세션 칸반을 패널로 보고, 카드를 누르면 그 세션의 터미널로 가요. 입력 대기에는 패널에서 바로 답해요. 확장은 화면과 이동만 맡아요. 세션 상태 판단과 행동은 세션 칸반(`session-kanban.md`)이 그대로 맡아요.

## 역할

CLI Claude Code 를 herdr-app 안에서 Claude Desktop 처럼 쓰게 해요. 세션 목록을 보고, 누르면 그 세션 화면으로 가고, 오케스트레이터가 띄운 작업 세션을 부모 세션 밑에 묶어 봐요.

## 정책

1. **경계** — 확장은 atelier 의 공개 계약만 써요: 터미널에서 읽는 보드(세션 칸반 15)의 기계 출력과, 답하기·허용·거부·결정·보내기·중지 명령. atelier 본체는 herdr-app 을 몰라요. 보드 출력의 필드는 추가만 하고, 이름을 바꾸거나 빼지 않아요.
2. **설치** — `/atelier:setup` 의 선택 모듈 `herdr` 로 설치해요. herdr-app 이 없으면 건너뛰고 이유를 알려요. herdr-app 의 패널 검사를 통과해야 설치가 끝나요.
   - `/atelier:update` 는 herdr 모듈을 설치한 경우에만 패널을 플러그인 버전에 맞춰요. 원본과 다르면 묻지 않고 백업한 뒤 덮어써요. 패널을 고쳐 쓰려면 herdr-app 의 복제 기능으로 다른 이름의 패널을 만들어요.
   - herdr-app 의 단축키 파일은 setup 도 update 도 고치지 않아요. 넣을 줄만 알려요. 사용자가 한 번 고친 단축키 파일에는 herdr-app 이 새 기본 단축키를 넣지 않아서예요.
3. **입구** — 단축키로 지금 탭의 오른쪽에 패널을 나눠 열어요. 패널은 그 탭과 함께 저장되고, 다른 pane 처럼 닫아요. 레이아웃은 바꾸지 않아요 — herdr-app 의 기본 레이아웃은 고칠 수 없고, 복제하면 앱 업데이트를 따라가지 않아서예요.
4. **보드** — 세션 칸반과 같은 세션·컬럼·순서·카드 내용을 보여요(세션 칸반 3·4·7). 패널이 보이는 동안 세션 칸반 pane 과 같은 주기로 다시 읽어요.
5. **이동** — 카드를 누르면 그 세션이 도는 herdr-app 터미널로 가요. 하위 에이전트라 pane 이 없는 터미널도 가요. 터미널 주소가 없는 세션(백그라운드 세션, herdr-app 밖의 세션)의 카드는 이동할 수 없다는 표시만 해요.
6. **부모–자식** — herdr-core 터미널로 띄운 세션은 그 부모 세션의 카드 밑에 묶어 보여요. 부모가 보드에 없으면(atelier 세션이 아님, 끝남, 보드에서 뺌) 자식은 일반 카드로 보여요.
7. **답하기** — 입력 대기 카드에서 권한 요청은 허용·거부, 질문은 선택지, 결정 요청은 답 버튼으로 답해요. 사람이 터미널에서 보낸 답과 같이 다뤄요(세션 칸반 11~13).
8. **세션 위치** — 모드가 로드된 세션은 자기가 도는 herdr-app 터미널 주소를 보드에 알려요.
   - herdr-core 터미널 안의 대화형 세션만 주소가 있어요.
   - 백그라운드 세션과 herdr 터미널 버전 창 안의 세션은, 그 세션을 띄운 터미널의 주소를 물려받았어도 주소가 없어요.

## 적용 지점

| 지점 | 동작 |
|---|---|
| 모드가 로드된 세션 | 자기 터미널 주소를 보드에 알려요(8) |
| herdr-app 패널 | 보드를 그리고, 이동하고, 입력 대기에 답해요(3~7) |
| `/atelier:setup` · `/atelier:update` | 패널을 설치하고 플러그인 버전에 맞춰요(2) |

## 실패 처리

- `atelier` CLI 가 없거나 실패함 → 패널에 이유 한 줄과 `/atelier:update` 안내만 그려요.
- 이동할 터미널이 이미 끝남 → 카드에 이유 한 줄을 보여요. 보드는 다음 갱신 때 맞춰져요.
- 답하기가 실패함 → 이유 한 줄만 보이고 아무것도 남기지 않아요.
- 설치 중 패널 검사가 실패함 → 설치 실패로 알리고 검사 출력을 보여요.

## 제약 조건

- 백그라운드 세션은 터미널이 없어서 카드에서 이동할 수 없어요.
- `claude attach` 로 터미널에 붙인 백그라운드 세션은 붙은 터미널의 주소를 모를 수 있어요.
- 세션 위치 판정은 Claude Code 가 문서로 약속하지 않은 신호에도 기대요. 버전이 바뀌어 신호가 사라지면, 백그라운드 세션이 자기를 띄운 터미널의 주소를 가진 것으로 보일 수 있어요.
- 같은 머신의 herdr-app 만 대상이에요.

## 미결정 사항

- 계정 전환 — 방식 미정(이슈의 결정 A).
- 탭 바 버튼 — herdr-app 이 mod 의 탭 바 버튼을 지원하면 더해요.
- 백그라운드 세션 카드에서 새 탭으로 `claude attach` 열기.
