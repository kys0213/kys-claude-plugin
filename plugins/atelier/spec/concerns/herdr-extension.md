# herdr-app 확장

> herdr-app 창에서 세션 칸반을 패널로 보고, 카드를 누르면 그 세션의 터미널로 가요. 입력 대기에는 패널에서 바로 답해요. 확장은 화면과 이동만 맡아요. 세션 상태 판단과 행동은 세션 칸반(`session-kanban.md`)이 그대로 맡아요.

## 역할

CLI Claude Code 를 herdr-app 안에서 Claude Desktop 처럼 쓰게 해요. 세션 목록을 보고, 누르면 그 세션 화면으로 가고, 오케스트레이터가 띄운 작업 세션을 부모 세션 밑에 묶어 봐요.

## 정책

1. **경계** — 확장은 atelier 의 공개 계약만 써요: 터미널에서 읽는 보드(세션 칸반 15)의 기계 출력과, 답하기·허용·거부·결정·보내기·중지 명령, 열린 탭 기록(9). atelier 본체는 herdr-app 을 몰라요. 보드 출력의 필드는 추가만 하고, 이름을 바꾸거나 빼지 않아요.
2. **설치** — `/atelier:setup` 의 선택 모듈 `herdr` 로 설치해요. herdr-app 이 없으면 건너뛰고 이유를 알려요. herdr-app 의 패널 검사를 통과해야 설치가 끝나요.
   - `/atelier:update` 는 herdr 모듈을 설치한 경우에만 패널을 플러그인 버전에 맞춰요. 원본과 다르면 묻지 않고 백업한 뒤 덮어써요. 패널을 고쳐 쓰려면 herdr-app 의 복제 기능으로 다른 이름의 패널을 만들어요.
   - herdr-app 의 단축키 파일은 setup 도 update 도 고치지 않아요. 넣을 줄만 알려요. 사용자가 한 번 고친 단축키 파일에는 herdr-app 이 새 기본 단축키를 넣지 않아서예요.
3. **입구** — 단축키로 지금 탭의 오른쪽에 패널을 나눠 열어요. 패널은 그 탭과 함께 저장되고, 다른 pane 처럼 닫아요. 레이아웃은 바꾸지 않아요 — herdr-app 의 기본 레이아웃은 고칠 수 없고, 복제하면 앱 업데이트를 따라가지 않아서예요.
4. **보드** — 세션 칸반과 같은 세션·컬럼·순서·카드 내용을 보여요(세션 칸반 3·4·7). 세션 기록이 바뀔 때 다시 읽고, 머문 시간이 흐르도록 30초마다 한 번 더 읽어요. 읽은 내용이 같으면 다시 그리지 않아요. 기록 폴더를 감시할 수 없으면 세션 칸반 pane 과 같은 주기로 읽어요. herdr-app 은 다른 탭에 있는 패널도 계속 살려 두고, 패널을 다시 그리면 창 전체를 다시 그려서예요.
5. **이동** — 카드는 herdr-app 안의 자리에 따라 셋 중 하나예요. 자리는 보드에서 계산하고, 보드를 여럿 띄워도·다시 열어도 같아요.

   | 자리 | 조건 | 카드 표시 | 누르면 |
   |---|---|---|---|
   | 열림 | 세션의 터미널(8) 또는 보드가 연 탭의 터미널(9)이 살아 있고 그 안에서 Claude 가 돌고 있음. 둘 다면 세션의 것 | 없음 | 그 터미널로 가요. 하위 에이전트라 pane 이 없는 터미널도 가요 |
   | 여는 중 | 보드가 탭을 맡은 지 15초 안이고, 그 탭에서 아직 Claude 가 돌지 않음 | 여는 중 | 아무것도 하지 않아요 |
   | 닫힘 | 위 둘이 아님: 터미널이 끝났거나, 없거나, Claude 가 끝나 셸이나 다른 프로그램만 남음 | 터미널 밖 세션 · 눌러서 열기 | 새 탭을 열어요(아래) |

   - 닫힌 카드를 누르면 먼저 그 카드를 읽을 때 본 열린 탭 기록 위에 새 탭을 맡아요(9). 그 사이 다른 보드가 맡았으면 열지 않아요.
   - 그다음 실행 중인 Claude 세션 목록(`claude agents --json`)으로 상태를 확인해요. 보드를 다시 읽을 때는 확인하지 않아요. 목록을 읽는 데 1초쯤 걸려서예요.
   - 실행 중이 아닌 세션은 세션 폴더에서 새 탭을 열어 대화를 이어요(`claude --resume`). 그 폴더에서 열어야 대화를 찾아요.
   - 백그라운드 세션은 새 탭을 열어 그 세션에 붙어요(`claude attach`). 이어 열면 같은 대화에 별개의 프로세스가 생겨요.
   - 다른 곳에서 실행 중인 세션은 탭을 열지 않고 맡은 것을 돌려놔요. 그렇다고 안내하고, 카드가 바뀌면 안내를 지워요. 이어 열면 같은 대화에 두 번째 프로세스가 붙어요.
   - 새 탭은 Claude 를 띄우기 전에 자기 터미널 주소를 열린 탭 기록에 남겨요. 백그라운드 세션은 붙은 탭의 주소를 스스로 알리지 못해서예요(8).
   - herdr-app 은 에이전트가 끝나도 그 터미널의 셸을 남겨 둬요. Claude 가 돌지 않는 터미널로는 가지 않고, 그 탭을 다시 쓰지도 않아요.
   - 여는 중인 카드는 보류 시간이 지나면 기록이 바뀌지 않아도 닫힘으로 다시 그려요.
6. **부모–자식** — herdr-core 터미널로 띄운 세션은 그 부모 세션의 카드 밑에 묶어 보여요. 부모가 보드에 없으면(atelier 세션이 아님, 끝남, 보드에서 뺌) 자식은 일반 카드로 보여요.
7. **답하기** — 입력 대기 카드에서 권한 요청은 허용·거부, 질문은 선택지, 결정 요청은 답 버튼으로 답해요. 사람이 터미널에서 보낸 답과 같이 다뤄요(세션 칸반 11~13).
8. **세션 위치** — 모드가 로드된 세션은 자기가 도는 herdr-app 터미널 주소를 보드에 알려요.
   - herdr-core 터미널 안의 대화형 세션만 주소가 있어요.
   - 백그라운드 세션과 herdr 터미널 버전 창 안의 세션은, 그 세션을 띄운 터미널의 주소를 물려받았어도 주소가 없어요.
9. **열린 탭 기록** — 보드가 연 탭은 세션마다 하나씩 atelier 가 기록해요. 세션 기록과 따로 둬요 — 세션 기록은 그 세션의 프로세스만 고쳐 써요.
   - 기록은 "여는 중"(맡은 시각)이거나 탭이 알린 터미널 주소예요. 보드 출력의 세션마다 함께 실려요.
   - 새 탭은 보드가 본 기록 위에만 맡을 수 있어요. 본 것과 다르면 거절해요. 그래서 두 보드가 같은 카드를 거의 동시에 눌러도 탭은 하나만 열려요.
   - 맡은 것을 돌려놓을 때도 본 기록일 때만 지워요. 그 사이 탭이 알린 주소는 지우지 않아요.
   - 세션을 잊으면(`forget`) 이 기록도 지워요. 기록이 바뀌면 보드는 세션 기록이 바뀔 때처럼 다시 읽어요(4).

## 적용 지점

| 지점 | 동작 |
|---|---|
| 모드가 로드된 세션 | 자기 터미널 주소를 보드에 알려요(8) |
| herdr-app 패널 | 보드를 그리고, 이동하고, 입력 대기에 답해요(3~7). 새 탭을 맡고 돌려놔요(9) |
| 패널이 연 탭 | Claude 를 띄우기 전에 자기 터미널 주소를 남겨요(9) |
| `/atelier:setup` · `/atelier:update` | 패널을 설치하고 플러그인 버전에 맞춰요(2) |

## 실패 처리

- `atelier` CLI 가 없거나 실패함 → 패널에 이유 한 줄과 `/atelier:update` 안내만 그려요.
- 새 탭을 맡지 못함(그 사이 다른 보드가 맡음) → 이유 한 줄을 보이고 보드를 다시 읽어요.
- 실행 중인 세션 목록을 읽지 못함 → 맡은 것을 돌려놓고 이동할 터미널이 없다고만 표시해요. 상태를 모르는 채로 이어 열지 않아요.
- 세션 폴더가 없음(지운 worktree 등) → 맡은 것을 돌려놓고, 탭을 열지 않고 그 폴더가 없다고 표시해요.
- 맡은 것을 돌려놓지 못함 → 15초가 지나면 카드가 닫힘으로 돌아가요.
- 새 탭이 터미널 주소를 알리지 못함(`atelier` 실행 실패 등) → 탭은 열리고, 15초 뒤 카드가 닫힘으로 돌아가요.
- 답하기가 실패함 → 이유 한 줄만 보이고 아무것도 남기지 않아요.
- 설치 중 패널 검사가 실패함 → 설치 실패로 알리고 검사 출력을 보여요.

## 제약 조건

- 패널 밖에서 `claude attach` 로 터미널에 붙인 백그라운드 세션은, 붙은 터미널의 주소를 보드가 몰라요. 그 카드는 닫힘으로 보이고, 누르면 새 탭에서 한 번 더 붙어요.
- 세션 위치 판정은 Claude Code 가 문서로 약속하지 않은 신호에도 기대요. 버전이 바뀌어 신호가 사라지면, 백그라운드 세션이 자기를 띄운 터미널의 주소를 가진 것으로 보일 수 있어요.
- 같은 머신의 herdr-app 만 대상이에요.

## 미결정 사항

- 계정 전환 — 방식 미정(이슈의 결정 A).
- 탭 바 버튼 — herdr-app 이 mod 의 탭 바 버튼을 지원하면 더해요.
