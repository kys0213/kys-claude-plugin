# 세션 칸반

> 이 머신에서 atelier 가 켜진 Claude Code 세션 전체를 한 pane 의 칸반으로 보여줘요. 세션 하나가 카드 하나이고, 컬럼은 세션이 지금 무엇을 기다리는지예요.

## 역할

여러 세션을 동시에 돌릴 때 "어느 세션이 내 답을 기다리는지", "어느 세션이 아직 일하는지", "어느 세션이 죽었는지"를 한눈에 보게 해요.

## 정책

1. **대상** — atelier 모드가 로드된 세션만 보여요. 모드가 없는 세션·다른 머신의 세션은 대상이 아니에요.
2. **열기** — `/kanban` 으로 pane 을 열고, 다시 입력하면 닫아요. 넓은 화면은 대화 옆, 좁은 화면은 프롬프트 위에 놓여요.
3. **컬럼** — 순서는 고정이에요: 입력 대기 → 작업 중 → 쉬는 중 → 응답 없음. 빈 컬럼도 보여요.
   - **입력 대기**: 권한 확인·질문(AskUserQuestion)·MCP 입력 요청에 사람이 답하기를 기다려요. 카드에 무엇을 기다리는지(예: `권한 요청: Bash`, `질문`) 표시해요.
   - **작업 중**: 프롬프트를 받았거나 도구를 실행하고 있어요. 권한 확인에 답한 직후부터 작업 중이에요.
   - **쉬는 중**: 턴이 끝나 다음 프롬프트를 기다려요. 막 시작한 세션도 여기예요.
   - **응답 없음**: 세션 프로세스의 생존 신호가 2분 넘게 끊겼어요(비정상 종료·멈춤). 직전 컬럼과 상관없이 여기로 옮겨요.
4. **카드** — 저장소 이름(없으면 작업 디렉토리 이름), 그 컬럼에 머문 시간, 세션 제목(없으면 첫 프롬프트를 한 줄로 접어 60자)을 보여요. pane 을 연 세션 자신은 `▶` 로 표시해요.
5. **머문 시간** — 지금 컬럼에 들어온 시각부터 세요. 같은 상태가 이어지는 동안(도구를 여러 번 실행하는 동안 등)은 다시 세지 않아요. 응답 없음은 마지막 생존 신호부터 세요.
6. **정렬** — 입력 대기·작업 중은 오래 기다린 세션이 위, 쉬는 중·응답 없음은 최근 세션이 위예요.
7. **사라짐** — 세션이 정상 종료하면 카드가 바로 사라져요. 생존 신호가 24시간 넘게 없으면 그때 사라져요.
8. **갱신** — pane 이 열려 있는 동안 2초마다 다시 그려요. 닫혀 있으면 읽지 않아요.

## 적용 지점

| 지점 | 동작 |
|---|---|
| 각 세션의 모드 | 프롬프트·턴 시작/끝·권한 요청·알림·도구 결과·spinner 재표시·종료를 사실 그대로 세션별로 기록하고, 30초마다 생존 신호를 남겨요 |
| atelier CLI (보드 판정) | 기록 묶음과 현재 시각·임계값을 받아 컬럼별 카드와 지울 세션 목록을 돌려줘요. 판정은 전부 여기서 해요 |
| pane | 받은 보드를 그리기만 하고, 지울 세션의 기록을 지워요 |

## 실패 처리

- `atelier` CLI 가 없거나 실패함 → pane 에 이유 한 줄과 `/atelier:update` 안내만 그려요. 세션 동작에는 영향이 없어요.
- 기록을 읽지 못함(다른 버전이 쓴 기록·깨진 기록) → 그 카드만 빼요. 그 기록은 지우지 않아요.
- 기록 쓰기 실패 → 다음 이벤트·생존 신호 때 다시 써요. 원래 이벤트는 막지 않아요.

## 제약 조건

- 권한 확인에 답한 순간을 알리는 이벤트가 없어요. 그래서 답한 뒤 Claude Code 가 spinner 를 다시 그리는 것으로 작업 재개를 판단해요. spinner 를 그리지 않는 환경(`claude -p` 등)에서는 도구가 끝날 때까지 입력 대기로 남아요.
- 같은 머신의 세션만 공유해요(모드 저장소가 머신 로컬이에요).
