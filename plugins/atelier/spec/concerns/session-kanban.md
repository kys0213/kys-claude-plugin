# 세션 칸반

> 이 머신에서 atelier 가 켜진 Claude Code 세션 전체를 한 pane 의 칸반으로 보여줘요. 세션 하나가 카드 하나이고, 컬럼은 세션이 지금 무엇을 기다리는지예요. 세션이 질문하면 칸반에서 바로 답할 수 있어요.

## 역할

여러 세션을 동시에 돌릴 때 "어느 세션이 내 답을 기다리는지", "어느 세션이 아직 일하는지·어디까지 했는지", "어느 세션이 죽었는지"를 한눈에 보게 하고, 질문에는 그 세션으로 가지 않고 답하게 해요.

## 정책

1. **대상** — atelier 모드가 로드된 세션만 보여요. 모드가 없는 세션·다른 머신의 세션은 대상이 아니에요.
2. **열기** — `/kanban` 으로 pane 을 열고, 다시 입력하면 닫아요. 넓은 화면은 대화 옆, 좁은 화면은 프롬프트 위에 놓여요.
3. **컬럼** — 순서는 고정이에요: 입력 대기 → 작업 중 → 쉬는 중 → 응답 없음. 빈 컬럼도 보여요.
   - **입력 대기**: 권한 확인·질문(AskUserQuestion)·MCP 입력 요청에 사람이 답하기를 기다려요. 카드에 무엇을 기다리는지(예: `권한 요청: Bash`, `질문`) 표시해요.
   - **작업 중**: 프롬프트를 받았거나 도구를 실행하고 있어요. 권한 확인·질문에 답한 직후부터 작업 중이에요(칸반에서 답한 경우 포함).
   - **쉬는 중**: 턴이 끝나 다음 프롬프트를 기다려요. 막 시작한 세션도 여기예요.
   - **응답 없음**: 세션 프로세스의 생존 신호가 2분 넘게 끊겼어요(비정상 종료·멈춤). 직전 컬럼과 상관없이 여기로 옮겨요.
4. **카드** — 저장소 이름(없으면 작업 디렉토리 이름), 그 컬럼에 머문 시간, 세션 제목(없으면 첫 프롬프트를 한 줄로 접어 60자)을 보여요. pane 을 연 세션 자신은 `▶` 로 표시해요. 진행 상황이 있으면 한 줄 더 보여요.
5. **진행 상황** — 응답 없음이 아닌 카드에 `할 일 <완료>/<전체> · <진행 중인 할 일>` 을, 작업 중 카드에는 이어서 `▸ <도구>: <대상>` 을 보여요.
   - 할 일은 세션의 Task 목록(`TaskCreate`·`TaskUpdate`)이 있으면 그것을, 없으면 `TodoWrite` 목록을 세요. 지운 할 일은 세지 않아요. 할 일이 없으면 이 부분을 빼요.
   - 진행 중인 할 일은 첫 번째 진행 중 항목의 진행형 문구(없으면 제목)이고, 40자로 잘라요.
   - 도구 대상은 도구 입력의 설명·파일·패턴·주소·명령 순으로 처음 있는 값이에요. 파일 경로는 파일 이름만, 40자로 잘라요. 턴이 끝나면 지워요.
6. **머문 시간** — 지금 컬럼에 들어온 시각부터 세요. 같은 상태가 이어지는 동안(도구를 여러 번 실행하는 동안 등)은 다시 세지 않아요. 응답 없음은 마지막 생존 신호부터 세요.
7. **정렬** — 입력 대기·작업 중은 오래 기다린 세션이 위, 쉬는 중·응답 없음은 최근 세션이 위예요.
8. **사라짐** — 세션이 정상 종료하면 카드가 바로 사라져요. 생존 신호가 24시간 넘게 없으면 그때 사라져요. 그 세션에 남은 칸반 답도 같이 지워요.
9. **갱신** — pane 이 열려 있는 동안 2초마다 다시 그려요. 닫혀 있으면 보드를 읽지 않아요.
10. **질문에 답하기** — 입력 대기(`질문`) 카드의 질문은 보드 아래에 펼쳐 그려요: 질문마다 머리말·문장, 선택지(설명 포함), 직접 입력 칸, 그리고 보내기 버튼.
    - 선택지를 누르면 고르고, 복수 선택 질문은 다시 누르면 빠져요. 직접 입력을 보내면(Enter) 그 질문의 답이 그 글이 되고 고른 선택지는 지워져요.
    - 보내기는 모든 질문에 답이 있을 때만 받아요. 없으면 어느 질문이 비었는지 한 줄로 보여요. 복수 선택 답은 선택지 순서대로 `, ` 로 이어요.
    - 질문한 세션은 2초 안에 그 답을 받아 질문 화면을 닫고, 사람이 답한 것과 같게 작업을 이어가요. 질문 화면에서 먼저 답하면 그 답이 쓰이고 칸반의 답은 버려요.
    - 보낸 뒤에는 "보냈어요" 만 보이고, 질문이 끝나면 카드에서 사라져요.

## 적용 지점

| 지점 | 동작 |
|---|---|
| 각 세션의 모드 | 프롬프트·턴 시작/끝·권한 요청·알림·도구 결과·spinner 재표시·종료를 사실 그대로 세션별로 기록하고, 30초마다 생존 신호를 남겨요. 도구 호출(지금 하는 일)·할 일 목록·열린 질문도 기록하고, 열린 질문의 칸반 답을 기다려요 |
| atelier CLI (보드 판정) | 기록 묶음과 현재 시각·임계값을 받아 컬럼별 카드(진행 상황·열린 질문 포함)와 지울 세션 목록을 돌려줘요. 판정은 전부 여기서 해요 |
| atelier CLI (답 만들기) | 질문과 고른 선택지·직접 입력을 받아 질문 순서의 답 목록을 돌려주거나, 빈 질문·없는 선택지를 거부해요 |
| pane | 받은 보드를 그리고, 질문의 선택을 모아 답을 써요. 지울 세션의 기록과 남은 답을 지워요 |

## 실패 처리

- `atelier` CLI 가 없거나 실패함 → pane 에 이유 한 줄과 `/atelier:update` 안내만 그려요. 세션 동작에는 영향이 없어요.
- 기록을 읽지 못함(다른 버전이 쓴 기록·깨진 기록) → 그 카드만 빼요. 그 기록은 지우지 않아요.
- 기록 쓰기 실패 → 다음 이벤트·생존 신호 때 다시 써요. 원래 이벤트는 막지 않아요.
- 답 만들기가 실패함(CLI 없음·거부) → pane 에 이유 한 줄만 보이고 아무것도 쓰지 않아요. 질문 화면은 그대로 열려 있어요.
- 이미 끝난 질문에 칸반 답이 늦게 써짐 → 아무도 읽지 않고, 그 세션이 사라질 때 지워져요.

## 제약 조건

- 권한 확인에 답한 순간을 알리는 이벤트가 없어요. 그래서 답한 뒤 Claude Code 가 spinner 를 다시 그리는 것으로 작업 재개를 판단해요. spinner 를 그리지 않는 환경(`claude -p` 등)에서는 도구가 끝날 때까지 입력 대기로 남아요.
- 같은 머신의 세션만 공유해요(모드 저장소가 머신 로컬이에요).
- 카드에서 그 세션 화면으로 이동하는 기능은 없어요. 모드가 다른 세션으로 화면을 바꿀 수단이 없어요.
- 칸반에서 답할 수 있는 것은 질문(AskUserQuestion)뿐이에요. 권한 확인은 그 세션에서 답해야 해요.
- 질문이 열린 채로 모드가 다시 로드되면, 그 질문은 칸반에서 답해도 받지 못해요. 질문 화면에서 답하면 돼요.
