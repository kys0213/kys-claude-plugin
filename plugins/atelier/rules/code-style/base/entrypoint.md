# 진입점

프로그램을 시작하고 끝내는 결정은 **진입점 한 곳**에서 한다. 나머지 코드는 값과 에러를 돌려줄 뿐 프로세스의 운명을 정하지 않는다.

- DO: 초기화는 진입점에서 명시적으로 호출한다. import·모듈 로드 부수효과나 main 이전에 실행되는 정적 초기화로 동작을 숨기지 않는다. 초기화 순서가 보이지 않고 실패를 다룰 곳이 없다.
- DO: 잘못된 인자·설정 같은 초기화 오류는 진입점까지 에러로 올린다. 진입점은 어떻게 고치면 되는지 말하는 메시지를 출력하고 0 이 아닌 코드로 끝낸다. 이런 오류에 스택 트레이스는 도움이 되지 않는다.
- DO: 프로세스를 끝내는 호출(exit 계열)은 진입점에만 둔다. 나머지 코드는 에러를 돌려준다.
- DO: exit 계열은 정리 코드(defer·drop·finally)를 건너뛸 수 있다. 본문을 에러를 돌려주는 함수로 빼고, 진입점은 그 결과로 종료 코드만 정한다.
- DO: 진입점은 조립만 한다 — 설정 읽기 → 의존성 생성·주입 → 실행 → 종료 코드. 로직은 테스트할 수 있는 함수로 뺀다.

```
main():
  result = run(args)          -- 정리는 run 안에서 끝난다
  exit(code_for(result))
```
