# 로깅

로그는 **나중에 문제를 진단할 사람**을 위한 기록이다. 같은 일을 여러 번 적거나 레벨을 부풀리면 정작 필요한 기록이 묻힌다.

- DO: 프로젝트가 정한 로깅 수단 하나를 쓴다.
- DO: 로그 메시지는 좋은 테스트 실패 메시지처럼 무엇이 잘못됐는지와 진단에 필요한 값(입력, 식별자)을 담는다.
- DON'T: 반환·전달하는 에러를 그 자리에서 로그한다. 같은 실패가 호출 층마다 찍힌다. 기록 여부와 빈도 제한은 최종 처리자가 정한다.
- DON'T: 개인정보(PII)나 비밀값(토큰·비밀번호·키)을 로그에 남긴다. 로그 저장소는 민감한 정보를 다루도록 만들어지지 않은 경우가 많다.
- DO: ERROR 레벨은 "누군가 조치해야 함"에만 쓴다. 더 심각해 보인다는 이유로 올리지 않는다.
- DO: 상세 로그의 인자를 만드는 비용이 크면 레벨이 켜졌는지 먼저 확인한다. 꺼진 레벨의 인자도 계산된다.

```
DON'T  log.error("load failed", err); return err      -- 호출자도 또 찍는다
DO     return wrap(err, "load order", id)              -- 최종 처리자가 한 번 기록
```
