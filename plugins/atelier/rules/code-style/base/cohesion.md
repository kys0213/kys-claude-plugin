# 응집

코드는 **소비하는 concern** 기준으로 묶는다. 기술 종류(모든 타입, 모든 상수)로 묶으면 한 기능을 고칠 때 여러 곳을 열어야 한다.

- DO: 사용처 1곳이면 소유 타입 옆 비공개·모듈 지역 항목으로 둔다. 모듈 2곳 이상이 쓰면 그때 공유 모듈로 승격하고 이름·공개 범위를 다시 정한다.
- DON'T: "나중에 공유할지도"로 미리 추출한다 — 추측한 경계는 다시 옮기게 된다. 공유 모듈 이름(util 등)은 기준이 아니다.
- DO: 인자를 그대로 넘기는 한 줄 위임 함수는 호출부에 inline 한다. 예외: 공개 API·추상의 구현처럼 경계를 이루는 위임.
- 판별: 지우면 영향받는 곳이 한 모듈뿐이면 그 안에 둔다. 공유 모듈에 사용처가 1곳만 남으면 되돌린다.
