# 이름

이름은 **쓰이는 자리에서** 읽힌다. 그 자리에서 이미 알 수 있는 정보는 빼고, 알 수 없는 정보만 담는다.

- DO: 이름은 담는 것·하는 일로 짓는다. 값을 돌려주면 명사형, 동작을 하면 동사형으로 짓는다.
- DO: 길이는 스코프에 비례하고 사용 횟수에 반비례한다. 넓은 범위에서 드물게 쓰는 이름일수록 구체적으로 짓는다.
- DON'T: 쓰이는 곳이 이미 주는 정보를 반복한다 (`widget.NewWidget` → `widget.New`, `config.writeConfigTo` → `config.writeTo`). 같은 이름끼리 구분할 때만 더한다.
- DON'T: 타입을 이름에 넣는다 (`userList`, `nameString`). 같은 값의 두 형태가 함께 있을 때만 구분한다 (`limitRaw`·`limit`).
- DON'T: 글자를 빼서 줄이거나(`cnt`, `mgr`), 프로젝트 밖 사람이 모를 약어를 쓴다. 널리 알려진 약어(URL, ID, HTTP)만 쓴다.
- DO: 비싸거나 실패할 수 있는 조회는 단순 접근자처럼 보이지 않게 짓는다 (`fetch`, `compute`, `load`).
- 한 글자 이름은 루프 인덱스·좌표·언어 관용 이름에만 쓴다.

판별: 이 이름을 쓰는 줄만 보고 무엇인지 알 수 있는가? 그 줄에 이미 있는 정보를 이름이 반복하고 있지는 않은가?
