# 투명한 래핑 (Transparent Wrapping)

래퍼(미들웨어, 인터셉터, 데코레이터, 계측·로깅·재시도를 덧씌우는 감싸기)는 **감싼 대상과 같은 계약**을 지킨다. 호출하는 쪽은 래퍼가 있든 없든 같은 결과를 받아야 한다. 래퍼가 계약을 바꾸면, 래퍼를 끼우거나 빼는 것만으로 동작이 달라져 원인을 찾기 어렵다.

## 지키는 것

| 항목 | 지킬 상태 |
|---|---|
| 완료 시점 | 원본이 끝날 때 래퍼도 끝난다. 원본의 작업을 백그라운드로 넘기고 먼저 반환하지 않는다. 원본이 동기면 래퍼도 동기다 |
| 에러 | 원본의 에러를 그대로 전파한다. 삼키지 않고, 다른 종류로 바꾸지 않고, 성공으로 바꾸지 않는다. 문맥을 덧붙일 때도 원래 에러의 종류를 호출 쪽이 판별할 수 있게 감싼다 |
| 인자·반환값 | 원본이 받는 인자와 돌려주는 값을 그대로 넘긴다. 몰래 기본값을 채우거나 값을 고치지 않는다 |
| 취소·시간 제한 | 호출 쪽이 준 취소 신호·시간 제한을 원본까지 그대로 전달한다 |

## DO

- 래퍼는 앞뒤에 부수 작업(계측, 로깅, 추적)만 덧붙이고 원본 호출 결과를 그대로 돌려준다.
- 부수 작업 자체가 실패해도 원본의 결과를 바꾸지 않는다. 부수 작업의 실패는 따로 기록한다.

```
wrapped(args):
  start = now()
  result = inner(args)            -- 인자 그대로
  record(elapsed(start), result)  -- 기록 실패는 결과에 영향 없음
  return result                   -- 에러 포함 그대로
```

## DON'T

- 원본의 에러를 잡아 로그만 남기고 성공(또는 빈 값)을 반환한다.
- 원본을 비동기로 띄우고 바로 반환해, 호출 쪽이 "끝났다"고 믿는 시점에 실제 작업이 아직 진행 중이게 한다.
- 래퍼 안에서 인자를 정규화·보정해 원본에 넘긴다. 보정이 필요하면 래퍼가 아니라 명시적인 단계로 드러낸다.

## 의도적으로 계약을 바꾸는 경우

재시도, 타임아웃, 회로 차단기처럼 **계약을 바꾸는 것이 목적인** 감싸기는 투명한 래퍼가 아니다. 이런 감싸기는 이름과 타입에 그 동작을 드러내고(예: "재시도하는 클라이언트"), 바뀐 계약(최대 시도 횟수, 마지막 에러를 돌려주는지 등)을 호출 쪽이 알 수 있게 한다.
