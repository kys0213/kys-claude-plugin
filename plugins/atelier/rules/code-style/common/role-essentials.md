# 역할별 핵심 (어느 파일에서나)

역할별 상세 규칙은 파일 이름이 맞을 때만 로드된다. 이름이 맞지 않는 파일에서도 아래 핵심은 지킨다.

- 설정: 한 곳에서 읽어 주입한다. 필수 설정엔 기본값을 두지 않는다.
- 외부 데이터: 경계에서 전용 타입으로 한 번 디코드해 코어에 넘긴다. 형태 검증과 의미 검증을 나눈다.
- 래퍼: 감싼 대상의 완료 시점·에러·인자를 바꾸지 않는다.
- 테스트: 의존성은 주입하고 전역 치환으로 바꾸지 않는다. 한 테스트에 한 행동(준비·실행·검증). 외부 인프라가 필요한 테스트는 그 여부 하나로 기본 실행에서 가른다. 구현 파일 안에 둔 테스트에도 같다.
