# 읽히는 본문

진입 함수(공개 API, 핸들러, 커맨드 실행부, 유스케이스) 본문은 **무엇을 어떤 순서로 하는가**만 보이게 쓴다. 독자는 본문으로 흐름을 잡고 필요한 단계만 들어간다.

- DO: 본문은 의도를 말하는 이름의 단계 호출 나열이다. 검증·계산·외부 호출·영속화는 각각 위임하고 진입 함수는 조율만 한다. 한 함수의 문장은 같은 추상 수준을 지킨다.
- DON'T: 여러 관심사를 한 본문에 인라인으로 섞는다. 구역 주석(`-- 1. 검증`)으로 단계를 나눈다 — 구역이 필요하면 함수로 뺄 신호다.
- DON'T: 의도를 말하는 이름을 붙일 수 없는 추출을 한다.
- 추출 신호: 지역 변수가 계속 는다, 관심사가 섞였다, 한 줄로 요약이 안 된다.
- 짧은 하위 함수는 대상이 아니며 세부를 직접 담아도 된다.

```
handle(request):
  input = validate(request)
  saved = orders.save(price(input))
  notify(saved)
```
