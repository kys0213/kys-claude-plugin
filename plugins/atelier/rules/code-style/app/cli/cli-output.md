# CLI 출력과 종료 코드

CLI 의 출력과 종료 코드는 **다른 프로그램이 기대는 계약**이다. 사람이 보는 화면이기 전에 파이프·스크립트·에이전트의 입력이다.

- DO: 결과는 stdout, 진행 상황·경고·오류 같은 진단은 stderr 로 낸다. 파이프로 넘긴 결과에 진단이 섞이지 않게 한다.
- DO: 종료 코드의 뜻을 정해 문서화한다. 0 은 성공이고, 그 밖의 코드는 호출자가 다르게 대응할 실패끼리 구분한다 (예: 인자 오류와 실행 실패). 한 번 정한 뜻은 바꾸지 않는다.
- DO: 다른 프로그램이 읽는 출력은 형식을 고정하고 사람용 출력과 나눈다 (줄 단위 `key=value`, `--json` 등). 순서도 정렬해 결정적으로 낸다.
- DON'T: 같은 입력에 대한 기계용 출력이 실행 환경(터미널 폭, 로케일, 현재 시각)에 따라 달라진다.
- DO: 입력을 기다리는 질문은 터미널에 연결됐을 때만 한다. 모든 질문에 대응하는 인자를 둬 비대화형으로도 끝까지 돌 수 있게 한다.
- DO: 사용자 오류 메시지는 무엇이 잘못됐고 어떻게 고치는지 말한다 (허용 값 목록, 다음에 할 명령). 스택 트레이스·내부 타입 이름을 보여 주지 않는다.
- DO: 색·진행 표시줄은 터미널일 때만 쓰고 끌 수 있게 한다.

```
$ tool check --json > report.json   # stdout: 결과만
warning: 2 rules skipped            # stderr: 진단
$ echo $?
1                                   # 문서화된 뜻: "갱신할 것이 있음"
```

판별: 이 출력을 다른 프로그램이 파싱한다면, 문구나 순서를 바꿨을 때 그 프로그램이 깨지는가? 깨진다면 그 출력은 계약이니 형식을 고정하고 문서화한다.
