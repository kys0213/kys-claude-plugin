# Rules 작성법

rules(CLAUDE.md·AGENTS.md·`.claude/rules/`)는 **작업자가 어떻게 일하는가**를 적는 지침이다 — 컨벤션, 경계 원칙, 반복 실수 방지, 전체 규격을 빠르게 이해시키는 안내. 제품 규격은 spec이, 시점 기록은 plan이 담당한다 (구분 기준: CLAUDE.md의 "문서 계층 (Spec / Rules / Plan)" 절).

- **역할·계약·불변식으로 서술한다**: 실제 코드 조각·실제 식별자·실제 경로 같은 구현 스냅샷을 담지 않는다. 판별 질문 — "구현 디테일이 바뀌면 이 문장이 깨지는가?" 깨지면 일반화한다. 예시는 의사코드·형태 패턴까지만 쓴다. (예외: frontmatter 스키마·CLI 출력 포맷처럼 형식이 곧 계약인 것은 구체 표기 허용)
- **로딩 모드를 성격에 맞춘다**: 레이어·언어 한정 컨벤션은 `paths:`로 조건부 로드하고, 안전·금지 규칙과 세션 내내 유지할 규칙은 `paths:` 없이 상시 로드한다.
- **동기화 의무**: 같은 실수가 반복되면 지침을 추가하고, 작업 방식이 바뀌면 갱신한다. rules를 현실과 어긋난 채 두지 않는다.
- 하나의 파일은 하나의 관심사만 다룬다. DO/DON'T와 체크리스트로 위반을 판별 가능하게 적는다.
