# 턴 끝 응답의 질문을 Haiku 로 판정해 입력 대기로 옮기기

> **Plan — 이 시점의 결정 기록.** 현재 정책의 신뢰 소스가 아니다.
> 날짜: 2026-11-12 · 브랜치: claude/modest-pascal-lqzatp · 승인 출처: 사용자 승인 (2026-11-12 "haiku 로 필요 유무만 판단하게 할 수 없나?" · 카드 표시는 "결정 요청에 합치기" · "rust 가 아니라 claude mods 에서도 호출 가능")

## 배경

세션이 턴 끝 응답에서 평문으로 사람에게 묻고 끝나면(AskUserQuestion·WrapUp 없이) 카드가 쉬는 중에 놓인다. 실제로는 사람의 답을 기다리는 세션이다. 턴 끝 입력 대기는 그때까지 `WrapUp` 의 `ask` 가 있을 때만 생겼다.

## 결정

- 판단: 모드 모듈이 `$.model.classify(text, labels)` 로 "답을 기다림 / 답이 필요 없음" 두 라벨 중 하나만 고르게 한다. 기본 모델은 엔진의 small-fast 모델(Haiku). 응답 꼬리 4,000자만 넘긴다.
- 언제: 메인 루프의 `turn.complete` 마다. 중단된 턴·빈 응답·같은 턴에 이미 결정(WrapUp)이 있으면 부르지 않는다.
- 표시: 기존 `결정 요청` 에 합친다 — 선택지 없는 결정. 질문 자리는 응답의 끝 200자(`orig_len.ask` 에 원래 길이). 상세의 직접 입력·결정 답 요청·위임의 "결정은 늘 묻기"·장부 기록이 그대로 적용된다.
- 비동기: 턴 끝을 기다리게 하지 않는다. 판정이 오기 전에 다음 턴이 시작되면(`s.turnEnd` 객체가 바뀜) 버린다. 기록 시점에 결정이 이미 있으면 덮지 않는다.
- 실패(모델 호출 throw)는 결정을 남기지 않는다 — 쉬는 중 그대로 (fail-open).
- 책임 경계: LLM 판단은 지능 호출이라 CLI 에 두지 않는다. CLI·Rust 변경 없음.

## 버린 선택지

- `claude -p --safe-mode --model haiku …` 프로세스를 CLI 가 argv 로 만들어 모듈이 실행: 처음 구현했으나 사용자가 모드 엔진의 `$.model` 로 부를 수 있다고 짚어 버렸다. 프로세스 기동 비용, 인증·설치 의존, Rust 표면 추가가 없어진다.
- 질문 문장까지 모델로 뽑기(`$.model.complete` + JSON): 사용자가 "필요 유무만" 판단하라고 했다. 질문은 응답 끝으로 충분하다.
- 모델 자기 표시(전용 도구 + 세션 시작 안내), CLI 규칙 판정(물음표·어미), 새 대기 종류 `답 요청`.

## 확인

- 엔진 classify 프롬프트를 흉내 낸 Haiku 샘플 5개(완료 보고·A/B 선택·"필요하면 말씀해 주세요"·PR 여부 질문·수사적 질문) 모두 기대대로 판정.
