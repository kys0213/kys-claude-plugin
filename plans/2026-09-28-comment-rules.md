# 언어 공통 주석 규칙을 추가하고 이번 브랜치의 새 코드에 적용한다

> **Plan — 이 시점의 결정 기록.** 현재 정책의 신뢰 소스가 아니다.
> 날짜: 2026-09-28 · 브랜치: claude/ecstatic-hawking-e8ov7q · 이슈: 없음 (기존 코드 정리는 별도 이슈) · 승인 출처: 사용자 승인

## 요구사항

1. 주석 규칙을 `.claude/rules/` 에 추가한다. 언어와 무관하게 적용된다.
2. 이번 브랜치에서 새로 쓴 코드(orchestrator CLI, hooks 모듈, 두 쪽 테스트)의 주석을 규칙에 맞춘다.
3. 기존 코드의 위반은 이번에 고치지 않고 정리 이슈로 넘긴다.

## 현재 상태

- 추적 파일은 Rust 108, Go 32, Shell 20, TypeScript 3 개다. 문서 주석 관용이 언어마다 다르다 — Rust `///`·`//!`, Go 식별자로 시작하는 `//`, TS `/** */`, Shell `#`.
- 사용자가 준 초안은 TS 전용이라 서술 주석을 `/** */` 로 강제한다. Rust·Go 관용과 충돌한다.
- 기존 rules 는 frontmatter 에 `paths` 만 쓴다. `rules-writing` 정책은 예시를 형태 패턴까지만 쓰라고 한다.
- 기존 코드에 이슈·PR 번호를 인용한 주석이 38줄(모두 Rust), 문서 포인터가 32줄(대부분 decision-graph 검사 스크립트) 있다.
- 새 코드에도 위반이 있다 — `spawn_check.rs` 의 확인되지 않은 외부 동작 단정, 정책 근거 복제, 스킬 불변식 포인터.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 초안을 TS 전용으로 그대로 둔다 | 버림 — 주력 언어인 Rust 에 적용되지 않는다 |
| 서술 주석을 모든 언어에서 블록 주석으로 강제 | 버림 — rustdoc·godoc 관용을 깨고 도구가 문서로 읽지 못한다 |
| Rust 전용으로 바꾼다 | 버림 — 1절(무엇을 남기는가)은 언어와 무관하다 |
| 기존 70줄을 이번 브랜치에서 함께 정리 | 버림 — 번호만 지우면 맥락이 사라지고 문장마다 재작성이 필요해 별도 작업 규모다. 사용자 결정으로 이슈로 분리 |

## 결정

1. `.claude/rules/comments.md` — `paths` 는 `**/*.rs`, `**/*.go`, `**/*.ts`, `**/*.sh`. 1절은 공통 내용 규칙(code-local 맥락만, 복제·포인터·이력·what 금지, 외부 동작은 확인한 사실만). 2절은 언어별 문서 주석 관용 표와 라인 주석 예외(도구 디렉티브, 작업 마커, 단계 이름만 있는 테스트 마커). 테스트 코드에도 적용. 사용자에게 보이는 출력 문자열은 주석이 아니다. 기존 코드는 손대는 줄에만 적용하고 일괄 수정은 정리 이슈에서 한다.
2. 이번 브랜치의 새 파일 주석을 규칙에 맞춘다. 경고 문자열·compact-note 문구 같은 출력 문자열은 바꾸지 않는다.
3. 커밋 type 은 `fix(atelier)` — 새 코드의 주석 정리가 plugins 아래 변경이라 버전 범프 type 이 필요하다. 규칙 파일은 같은 커밋에 둔다.
